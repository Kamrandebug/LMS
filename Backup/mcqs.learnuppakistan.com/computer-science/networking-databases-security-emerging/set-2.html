Question 1/20 🔥 0 streak

Which topology requires a central hub or switch to connect all nodes in a network?

💡 Explanation

In a star topology, all devices are connected to a single central device such as a switch or a hub, which acts as a conduit to transmit messages.

In a bus topology, what is the purpose of a terminator?

💡 Explanation

Terminators are placed at both ends of a bus network to absorb signals and prevent them from bouncing back and causing interference, known as signal reflection.

Which network topology provides the highest level of redundancy and fault tolerance?

💡 Explanation

A full mesh topology connects every node to every other node, ensuring that if one path fails, data can be rerouted through another path.

A major disadvantage of a ring topology is that:

💡 Explanation

In a standard single-ring topology, data travels in one direction through each node; if one node fails, the loop is broken and communication stops.

Which topology is often described as a hierarchical arrangement of star networks?

💡 Explanation

A tree topology connects multiple star networks together, forming a parent-child relationship between nodes.

What is a primary benefit of using a star topology over a bus topology?

💡 Explanation

In a star topology, if one cable or device fails, the rest of the network remains functional, making it much easier to isolate and troubleshoot issues.

Which topology is most difficult and expensive to scale due to the high number of connections required?

💡 Explanation

Full mesh topology requires n(n-1)/2 connections; as the number of nodes increases, the cabling requirements grow exponentially, making it impractical for large networks.

In a bus topology, why is the network performance degraded as more nodes are added?

💡 Explanation

Since all devices share the same communication medium in a bus topology, adding more nodes increases the probability of data collisions and reduces overall bandwidth.

Which physical topology is characterized by having all nodes connected to a common shared medium, such as a coaxial cable?

💡 Explanation

A bus topology uses a single backbone cable that connects all nodes, allowing them to share the transmission medium.

In a ring topology, what technique is commonly used to prevent data collisions?

💡 Explanation

Token passing is the standard method in ring topologies where a 'token' is passed around; only the node with the token is allowed to transmit, preventing collisions.

Which network topology is considered a hybrid configuration that combines the characteristics of both bus and star topologies?

💡 Explanation

A tree topology connects multiple star networks to a central bus backbone, effectively merging the traits of both.

In a full mesh topology with 'n' nodes, what is the mathematical formula to calculate the number of physical links required?

💡 Explanation

The formula n(n-1)/2 determines the total number of unique physical connections needed to link every node to every other node.

What is the primary advantage of a tree topology in a large-scale network environment?

💡 Explanation

Tree topology allows for hierarchical grouping, which makes isolating and managing faults within specific branches easier.

In a hybrid topology, what is the main reason for combining different physical layouts?

💡 Explanation

Hybrid topologies are designed to meet specific functional needs, scalability, and performance requirements by leveraging the strengths of different topologies.

Which topology experiences 'bottleneck' issues if the central backbone or root node fails?

💡 Explanation

In a tree topology, the failure of the root or main trunk backbone cable disconnects the entire network branches connected to it.

A 'Partial Mesh' topology is typically implemented in enterprise networks to:

💡 Explanation

Partial mesh provides a balance between high reliability and cost-effectiveness by connecting critical nodes with redundant paths, unlike a full mesh.

Which topology is logically configured as a ring but physically wired as a star?

💡 Explanation

Token Ring networks utilize a Multi-Station Access Unit (MAU) which physically looks like a star hub, but logically the data travels in a ring pattern.

What is a disadvantage of a tree topology regarding cabling?

💡 Explanation

Due to its hierarchical structure, tree topologies require substantial cabling to connect branches to the main trunk.

Which of the following best describes the 'Daisy Chain' topology?

💡 Explanation

A daisy chain is a sequence of nodes connected together in a linear fashion, where each node is connected to the next.

In a mesh topology, if one path between two nodes fails, the network:

💡 Explanation

The defining feature of a mesh topology is its multiple paths, allowing for self-healing and redundancy if one connection fails.
