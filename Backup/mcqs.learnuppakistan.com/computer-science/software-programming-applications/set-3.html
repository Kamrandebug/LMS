Which feature in MS Word allows you to apply the same formatting from one part of a document to another?

💡 Explanation

Format Painter is designed to copy formatting attributes from a selected text or object and apply them to another location.

To convert existing text into a table in MS Word, which tab must you access?

💡 Explanation

In the Insert tab, clicking the Table group provides the 'Convert Text to Table' option.

In Mail Merge, the file that contains the variable information (names, addresses) is known as the:

💡 Explanation

The Data Source is the file containing the recipient information that is merged into the Main Document.

Which programming language is typically used for recording and writing Macros in MS Word?

💡 Explanation

Macros in Microsoft Office applications are written using VBA, which allows for task automation.

What is the purpose of a 'Section Break' in MS Word formatting?

💡 Explanation

Section breaks allow users to apply different formatting, such as column layouts or page numbering, to different sections of the same document.

What is the default file extension for an MS Word document that contains macros?

💡 Explanation

.docm is the specific extension for Word documents enabled with macros to distinguish them from standard .docx files.

Which feature is used in Word to keep a table from breaking across two pages?

💡 Explanation

Unchecking 'Allow row to break across pages' in the Table Properties prevents a row from being split between two pages.

When performing a Mail Merge, what are the placeholders like <<AddressBlock>> called?

💡 Explanation

Merge Fields are placeholders in the main document that are replaced by data from the data source during the merge process.

Which shortcut is primarily used to start recording a macro in Word if 'Record Macro' is not on the ribbon?

💡 Explanation

Alt + F8 opens the Macros dialog box, from where you can run, create, or record macros.

Which formatting option is used to adjust the spacing between lines of text in a paragraph?

💡 Explanation

Line and Paragraph Spacing is the standard tool used to control the vertical space between lines of text within a document.

Which dialog box in MS Word allows you to set specific margins for only a selected portion of a document?

💡 Explanation

The Page Setup dialog box allows users to apply margin settings to 'Selected text' or 'This point forward' by utilizing section breaks.

When creating a table in MS Word, which option is used to combine two or more cells into one single cell?

💡 Explanation

The 'Merge Cells' command in the Table Tools Layout tab is used to combine multiple selected cells into a single cell.

In Mail Merge, which document type is considered the 'Main Document'?

💡 Explanation

The main document contains the boilerplate text and the merge fields that will be populated by data from the data source.

Which feature in MS Word automatically corrects spelling and formatting errors as you type?

💡 Explanation

AutoCorrect is the feature that detects and fixes common typing errors and formatting mistakes automatically.

What is the primary function of a 'Style' in MS Word?

💡 Explanation

Styles allow users to apply a collection of formatting characteristics (font, size, color) to text consistently throughout a document.

Which view is required to effectively manage and see the boundaries of table cells in MS Word?

💡 Explanation

Print Layout view provides the most accurate representation of document elements, including table borders and spacing.

What does the 'AutoFit to Window' option do in an MS Word table?

💡 Explanation

The AutoFit to Window command resizes the table columns so that the total width of the table matches the width of the page.

Which security setting in MS Word prevents potentially malicious macros from running automatically?

💡 Explanation

The Trust Center is the central location where users configure security and privacy settings, including macro security policies.

What is the result of using the 'Sort' feature in an MS Word table column containing numbers?

💡 Explanation

The Sort feature in MS Word recognizes numeric data and sorts rows based on the mathematical value of the selected column.

Which keyboard shortcut is used to open the Visual Basic for Applications (VBA) editor to view macro code?

💡 Explanation

Alt + F11 is the standard shortcut in Microsoft Office applications to open the VBA Integrated Development Environment (IDE).
