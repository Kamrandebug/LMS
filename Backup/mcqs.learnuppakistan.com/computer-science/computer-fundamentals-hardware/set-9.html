What is the smallest unit of digital information in a computer system?

💡 Explanation

A bit (binary digit) is the fundamental unit of information in computing and digital communications, representing either a 0 or a 1.

How many bits constitute a single byte?

💡 Explanation

In standard modern computing, one byte is defined as exactly 8 bits.

Which of the following represents the largest unit of data storage?

💡 Explanation

A Petabyte (PB) equals 1,024 Terabytes, making it the largest among the given options.

In the binary-based prefix system (binary prefix), 1 Kilobyte (KB) is equal to:

💡 Explanation

In computing contexts, a Kilobyte is typically defined as 2 to the power of 10, which is 1024 bytes.

A group of 4 bits is known as a:

💡 Explanation

A nibble is a four-bit aggregation, or half of an eight-bit byte.

Which prefix represents 1,024 Megabytes?

💡 Explanation

1 Gigabyte (GB) is equal to 1,024 Megabytes (MB) in the binary system.

How many Terabytes (TB) are present in one Petabyte (PB)?

💡 Explanation

Following the binary power of 2 convention, 1 Petabyte = 1,024 Terabytes.

If a file size is 1024 KB, it is equal to:

💡 Explanation

Since 1 MB = 1024 KB, therefore 1024 KB = 1 MB.

Which sequence correctly orders the units of storage from smallest to largest?

💡 Explanation

The correct order of magnitude is bit < byte < Kilobyte < Megabyte < Gigabyte < Terabyte < Petabyte.

The prefix 'Giga' in computing represents which power of 2?

💡 Explanation

In computing units, Kilo is 2^10, Mega is 2^20, and Giga is 2^30.

Which unit of measurement is specifically defined as 2 to the power of 40 bytes?

💡 Explanation

In binary computing, 1 Terabyte is equal to 1,024 GB, which corresponds to 1,024^4 or 2^40 bytes.

In the context of standard storage capacity, how many bytes are contained in one Megabyte (MB) using the binary standard (1,024 base)?

💡 Explanation

1 Megabyte = 1,024 KB = 1,024 * 1,024 bytes = 1,048,576 bytes.

The term 'Nibble' refers to a grouping of bits equivalent to:

💡 Explanation

A nibble is a collection of 4 bits, also known as half a byte.

Which of the following is equivalent to 1,024 Petabytes?

💡 Explanation

In the storage hierarchy, 1,024 Petabytes (PB) equals 1 Exabyte (EB).

A standard computer word on a 32-bit architecture consists of how many bytes?

💡 Explanation

A 32-bit architecture processes 32 bits at a time; since 1 byte = 8 bits, 32/8 = 4 bytes.

Which unit is defined as 2 to the power of 10 bytes?

💡 Explanation

1 Kilobyte is defined as 1,024 bytes, which is 2^10.

What is the primary difference between the IEC standard (Kibi, Mebi, Gibi) and the SI decimal standard (Kilo, Mega, Giga)?

💡 Explanation

IEC prefixes (Kibi, Mebi) represent powers of 2 (binary), while SI prefixes (Kilo, Mega) represent powers of 10 (decimal).

If a disk drive is advertised as 1 Terabyte (TB) using the decimal standard (base 10), how many bytes is it approximately?

💡 Explanation

Manufacturers use the decimal system where 1 TB = 10^12 bytes, which is 1 trillion bytes.

How many bits are required to store one character in extended ASCII?

💡 Explanation

Extended ASCII uses 8 bits (1 byte) to represent characters.

Which of the following units represents the largest capacity storage in common modern enterprise hardware?

💡 Explanation

Out of the choices provided, the Petabyte is the largest unit of data capacity.
